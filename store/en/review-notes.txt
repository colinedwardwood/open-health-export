iCloud (guideline 5.1.3(ii)): the app never stores health data in iCloud by itself. Exports go only to a folder the person picks in Files. If the picked folder is in iCloud Drive, the app shows a warning ("This folder is in iCloud. Health archives written here leave this iPhone.") and does not save, test or write to the folder until the person taps "Use this iCloud folder anyway". "Choose another folder" keeps nothing. The confirmation is remembered for that one folder only; picking a different iCloud folder asks again. Every export, test and Export now run checks it, so an iCloud folder that was not confirmed receives no data and the run fails with an explanation. The app has no iCloud entitlement and no iCloud backend.
