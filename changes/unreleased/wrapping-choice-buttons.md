MQTT QoS, destination scope, display units, and time format are wrapping
buttons instead of UIKit menu pickers, so Dynamic Type audits see SwiftUI
controls that take the accessibility content-size category. Browser type
titles wrap at body size so rows such as flights climbed do not clip. Empty-state
toggles use primary contrast so RTL and pseudo-locale audits pass. Selected
choice buttons stay enabled with primary color instead of disabled gray.
Harness buttons use body type at a 44-point minimum so Dynamic Type audits
see scalable labels.
