MQTT topics can be AR-21 templates (`exporterId`, `batchId`). The harness can attach a
PKCS#12 client certificate for MQTTS. The HTTP loopback double can slow-loris a
response one byte at a time so URLSession contract tests cover delayed headers.
PKCS#12 imports are serialized across HTTPS and MQTTS setup to avoid
Security-framework decode races under concurrent destination verification.
