Open Health Exporter

An open-source Apple Health exporter that reports what it sent and whether it worked.

Not a medical device. This is not a medical device. It does not diagnose or treat anything.

Status and availability

Project
seeking-maintainers; Stage 3 implementation; v1 is not released.
iPhone and iPad
Minimum iOS/iPadOS 18.0. Full-history backfill needs foreground time on versions 18–25; on version 26 or later it can finish unattended.
Mac
Minimum macOS 15.0. The companion receives exports; it cannot read Apple Health. Its planned distribution is a notarised Developer ID download, outside the Mac App Store.

There is no App Store release and no prebuilt download today. The in-repo App Store copy has not been submitted.

What it exports

Every destination starts with zero Apple Health types. You explicitly choose its types and date range before it can export. The optional Core Daily preset contains 27 named routine families, including activity, energy, distance, heart-rate, sleep, mindful-session, body, respiratory, oxygen and workout data. Blood glucose and sensitive types are available only through the picker, not that preset.

The native archive is versioned ohe.wire/1 NDJSON. A local-file export can also write JSON, CSV and Health Auto Export compatibility sidecars. See the wire-format specification and machine-readable schema.

Where the data goes

Health data goes only to destinations you configure and enable:

  • a local folder;
  • an HTTPS endpoint;
  • an MQTT broker; or
  • the paired Mac companion.

There is no maintainer-bound telemetry, install counter, crash reporter or project account. A separate, disableable security-advisory request runs only on a visible foreground launch and sends no Health data.

Build it now

The current way to try the project is to build from source:

./scripts/build-from-source.sh

This generates the Xcode project and builds the simulator app and Mac companion. Running with Health data on a physical device requires Xcode and a free Personal Team. Follow the build instructions; do not expect an App Store install or release download yet.
