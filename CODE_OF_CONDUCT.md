# Code of conduct

This is a small health-data project, not a conference. We still do not accept harassment,
hate, or posting other people's health data.

**Enforcement contact:** Colin, via the GitHub Security Advisories tab or the email on
the owner account of this repository — a named person, not "the maintainers".

If you report conduct, you should hear an acknowledgement. With one maintainer that may
take days. This file does not promise an investigation we cannot staff. Serious reports
that we cannot handle will be refused honestly rather than silently dropped.

Unacceptable: harassment; doxxing; pasting real HealthKit records, tokens, or private
hostnames into public issues; or using the project spaces to sell medical interpretations.

Consequences, when a maintainer is available: warning, content removal, or a block from
the repository. There is no appeals committee.
